==================================================
INICIAR EVOLUTION API - FISIO ALTHEA
==================================================

1. Abrir o Prompt de Comando do Windows.

2. Acessar a pasta da Evolution API:

cd C:\Users\everton.balbinot\Projetos\evolution-api

3. Iniciar a Evolution API:

npm run start:prod

4. Aguardar aparecer uma mensagem semelhante a:

[SERVER] HTTP - ON: 8080

Isso significa que a Evolution API está funcionando.

IMPORTANTE
==================================================

O Prompt de Comando onde foi executado:

Para parar a Evolution API:

Ctrl + C
